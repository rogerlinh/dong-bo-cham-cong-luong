Đồng bộ chấm công và lương

Gộp bảng công, bảng lương của từng hợp đồng về một file Excel theo cấu trúc chuẩn, rồi đối chiếu lại với file gốc.

Chạy ngay trong trình duyệt. File của bạn được xử lý trên máy này, không tải lên máy chủ nào.

Mã nguồn
Đang tải bộ xử lý (lần đầu khoảng 20 MB, các lần sau nhanh hơn)…

File nguồn

Kéo thả file .xlsx vào đây, mỗi file là bảng công/lương của một hợp đồng. Biểu mẫu được nhận diện tự động.

    Đang đồng bộ…

    Kết quả đối chiếu

    Hợp đồngKỳ côngNhân viên Tổng lươngThực nhận
    file tổng / file gốc
    		 Doanh thu
    file tổng / file gốc
    		Cảnh báoĐối chiếu

    Con dấu "Khớp" nghĩa là thực nhận tính lại từ các cột trong file tổng bằng đúng thực nhận của file gốc, xét từng nhân viên. Cảnh báo chia 3 mức: Lỗi là số liệu sai chắc chắn, cần sửa file gốc; Nghi ngờ là bất thường cần người xem lại; Lưu ý chỉ để biết. Danh sách đầy đủ nằm ở sheet kiem_tra của file tổng hợp, và cột cuối sheet bang_luong đánh dấu từng nhân viên.
